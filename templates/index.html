What do these metrics mean?

Accuracy: fraction of all predictions that were correct. Balanced accuracy: average recall across classes. Precision: how often a predicted class was right. Recall: how much of a true class was found. F1: balances precision and recall.

01Data collection+

We imported {{ audit.input_count }} images from your ZIP, using only explicitly labelled source folders. Healthy regional folders were combined into Healthy; Basil_Plant_Unhealthy became Unhealthy. {{ coverage.missing_images }} listed images are absent. No replacement or synthetic training images were added.

02Data preprocessing+

Decode images, correct camera orientation, and convert to RGB. Reject invalid images, remove exact pixel duplicates, and group near-duplicates by perceptual hash (Hamming distance ≤ 4). This run retained {{ audit.valid_unique_count }} unique images. The grouped train/test split uses seed {{ r.seed }}. Plant identities remain unverified.

03Feature engineering+

Each image becomes {{ r.feature_count }} numeric features: RGB and HSV color histograms and statistics (108), local binary pattern texture (10), and HOG edge features (1,764). Resized copies use 128 × 128 pixels for color/texture and 64 × 64 for edges. Original images are unchanged. No image augmentation was used.

04Model selection+

Compare logistic regression, RBF SVM, random forest and nearest neighbors against a majority baseline. Seven parameter settings were tested on identical grouped validation folds. Scaling for logistic regression, SVM and nearest neighbors is fitted inside each training fold. Select by macro-F1; exact ties use fit time then name. No test labels guide selection.

05Model training+

The chosen {{ r.selected_model }} was fitted afresh on {{ r.development_images }} development images. {% if r.model_parameters.n_estimators is defined %}This model uses {{ r.model_parameters.n_estimators }} trees, balanced class weights, a minimum of {{ r.model_parameters.min_samples_leaf }} samples per leaf, and square-root feature sampling.{% else %}The fitted pipeline includes any scaling needed by the selected classifier; all fitted parameters come only from development data.{% endif %} It learns visual classification rules; it does not learn a medical diagnosis.

06Model evaluation+

Evaluate the selected model on {{ r.test_images }} held-out images: {{ pct(m.accuracy) }} accuracy and {{ '%.4f'|format(m.macro_f1) }} macro-F1. Report class precision, recall, the confusion matrix and a 500-resample group bootstrap interval. Repeatedly tuning on this test set would invalidate it as an independent final assessment.

07Model deployment+

The notebook saves the model, dataset fingerprint, split manifests, metrics and package versions. This Flask website serves the trusted saved model locally using Waitress. Uploads stay in memory on your computer; they are not stored, sent to an external model service, or added to training. After retraining the notebook, restart the website to load the new matching model and report.

THE CONCLUSION

Promising results.
Room to grow.

{{ r.selected_model }} achieved {{ pct(m.accuracy) }} accuracy on {{ r.test_images }} test images, after selection by grouped validation. It is a useful starting point for classifying images similar to this dataset.

The next step is independent testing on new plants, backgrounds, cameras and locations. Missing Pune data, unknown plant identities and collection differences mean this score must not be treated as universal leaf-health accuracy.
